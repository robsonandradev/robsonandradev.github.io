# Robson Andrade — personal website

Landing page pessoal publicada com GitHub Pages em:

https://robsonandradev.github.io

## Publicação

O site é estático e não possui etapa de build. O GitHub Pages publica o conteúdo da branch `master` diretamente da raiz do repositório.

Para publicar uma nova versão:

1. Revise e faça merge do pull request na `master`.
2. Acompanhe o deploy em **Settings → Pages** ou na aba **Actions**.
3. Aguarde a atualização de `https://robsonandradev.github.io`.

## Estrutura

- `index.html`: landing page principal, incluindo estilos responsivos.
- `about.html`: histórico profissional legado.
- `img/`, `css/` e `js/`: ativos preservados do site anterior.

A página principal foi mantida sem framework ou dependências para reduzir manutenção e garantir compatibilidade direta com o GitHub Pages.
